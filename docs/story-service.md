# 허들링 앱 — 유저스토리 (docs/prd.md 기준)

## 유저스토리

| # | 유저스토리 | PRD 출처 |
|---|---|---|
| 1 | 무료 학습자가 AI/Figma/자동화/바이브코딩 관련 콘텐츠를 부담 없이 둘러본다 | 3-1 |
| 2 | 유료 멤버가 강의자료, 다시보기, 템플릿, 프롬프트, 스킬 파일, 미션, 피드백을 한곳에서 확인한다 | 3-2 |
| 3 | 실험하는 멤버가 매달 만든 프롬프트, 스킬 파일, 자동화 템플릿, 업무 적용 사례를 제출하고 기록한다 | 3-3 |
| 4 | 판매를 원하는 멤버가 자신이 만든 자료 중 일부를 선택해 판매 신청한다 | 3-4 |
| 5 | 운영자가 무료/유료/판매용 자료를 구분해서 관리하고 멤버가 올린 자료를 검수한다 | 3-6 |

> 참고: 3-5(구매자)는 PRD에 "이번 범위 제외 · Phase 2"로 명시되어 있어 제외했습니다.
> 참고: 2번 스토리의 "피드백"은 섹션 3 원문 표현입니다. 단, PRD 6-4/7-3/9(MVP 범위 결정 사항)에서는 "미션 피드백 기능은 이번 범위에서 제외"로 명시되어 있어, MVP 구현 시에는 피드백 부분이 빠집니다.
